# 練習会の運営マニュアル

[ブラウザでアプリを開く](https://game-member-generator.web.app/) · [READMEに戻る](../README.md)

## 参加メンバーを準備する

1. **メンバー**タブで、名前・よみがな・性別を登録します。一覧がある場合は、右上のメニューから **データをインポート → ファイルからインポート** を選び、CSVまたはJSONを読み込みます。
2. 当日参加する人をオンにします。まとめて切り替える場合は **参加を一括変更** を使います。
3. 子守りなどで同時に出場できない2人は、メンバー編集の **同時出場制限** で相手を選びます。自動生成では別々のコートであっても、2人は同じラウンドに出場しません。

途中から来た人は、その時点で参加に切り替えます。次のラウンドだけ休む場合はメンバーのメニューで **一時休み**、以降のラウンドを休む場合は **早退** を選びます。

## コートを設定して試合を作る

1. **試合履歴**タブで **最初の試合を作成** を押します。2回目からは右下の **＋** で次のラウンドを作れます。
2. **自動**ではコート数に応じて試合形式が提案されます。**手動**では、たとえば1番コートを男子ダブルス、2番コートを混合ダブルスに設定できます。画面では男子が **MD**、女子が **WD**、混合が **XD**、性別の組み合わせを指定しない形式が **FD** と表示されます。
3. **スタート**を押し、コート別の組み合わせと休憩メンバーを確認します。表示中のラウンドを作り直す場合は、右下の更新アイコンを使います。

連続休みを避けると直近と同じ出場メンバーになる場合、確認が出ることがあります。**今のルールを続ける**と連続休みを避ける判断を優先します。**入れ替える**を選ぶ前に、画面に表示された連続休みの人数と最長回数を確認してください。

## 急きょ選手を交代する

1. 対象のラウンドを表示し、交代させる選手を長押しします。**選手を入れ替える**ボタンからも最初の選手を選べます。
2. 交代相手をタップします。たとえば、けがをした選手と休憩欄の選手を交代できます。
3. 交換後のコートと休憩欄を確認します。手動交代では、試合形式や同時出場制限を外れる交代も運営者の判断で行えます。

交代相手を選ぶ前なら **終了** で入れ替え操作を閉じられます。交代直後に戻す場合は、画面上部の **やり直し** アイコンを押して **戻す** を選びます。この操作は試合履歴の直前の変更を取り消します。

## 試合を生成できないとき

| 表示や状況 | 確認すること |
| --- | --- |
| 男性・女性・全体の人数が不足 | 当日の参加、一時休み、早退を確認し、人数に合うようにコートを減らすか、試合形式を変更します。 |
| 同時出場制限を解消できない | 設定したペアを確認し、片方が休憩に入れるようにコート数や試合形式を調整します。 |

## 費用を計算して精算する

1. **費用計算 → 出費を追加** でコート代やシャトル・ボール代などを入力します。消耗品は在庫から選ぶか、単価と使用数を入力します。
2. 明細をタップし、**支払った人**を設定します。全員で等分する場合は **均等**、費用ごとに負担する対象を指定する場合は **男女** を選びます。
3. **支払調整**で1人あたりの集金額、収支、支払人ごとの立替額を確認します。集金額は必要に応じて調整できます。
4. 消耗品の使用数を入力した日は、画面の日付を確認して **支払確定・記録を保存** を押すと消費記録が保存されます。保存した消費記録は **履歴** から確認できます。
